# Orizon Call releases

The installers of Orizon Call, the desktop recorder for Orizon, one GitHub
release per version: macOS (Apple Silicon and Intel), Windows and Linux,
with `SHA256SUMS.txt` and the release notes.

- Download the latest version from the Releases page.
- An Orizon deployment fetches the latest release from here by itself and
  offers it in **Transcriptions → Download Orizon Call**. Installed apps
  update through their Orizon server.

This repository holds only releases; the source lives elsewhere.
